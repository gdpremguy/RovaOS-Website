FROM DOWNLOAD TO DESKTOP

A few steps. Then you’re in.

No website can flash your USB directly. Use a trusted flashing tool and double-check which drive you select.

  1. 1

    Download & verify

    Download the ISO above and compare its SHA-256 checksum. Back up the USB you plan to use.

  2. 2

    Flash your USB

    On Windows, use Rufus ↗ and select DD image mode if prompted. On macOS or Linux, use balenaEtcher ↗. Write the image; don’t just copy the ISO file onto the drive.

    Flashing erases the selected drive. Confirm its model and capacity before writing.

  3. 3

    Boot into RovaOS

    Safely eject the USB, plug it into a compatible PC, restart, and choose it in the firmware boot menu. The boot-menu key varies by manufacturer, often F12, F9 or Esc.

    If it won’t boot, check firmware settings and compatibility below. Secure Boot support is not guaranteed on every machine.

  4. 4

    Make it portable. Make it stick.

    The ISO starts in a temporary session. To retain changes, open USB saving setup from Rova Settings and review the detected USB and confirmation carefully.

    Setup creates a save area on supported boot USBs. Restart when prompted, check for Persistent USB, then save a small file and reboot to confirm it survives. Files from the first temporary session are not automatically migrated.

    Saves, including Wi-Fi passwords, are unencrypted. Shut down before unplugging. Back up before reflashing: updates can erase your saves.

A QUICK COMPATIBILITY CHECK

Portable.
Not universal.

RovaOS is made for compatible 64-bit Intel and AMD PCs. Testing your actual computer is the best compatibility check.

A compatible PC

x86-64 Intel / AMD, with USB boot via BIOS or UEFI. Not for ARM devices, phones or Apple Silicon Macs.

A spare USB

It must fit the ISO, with additional room for saving. An 8 GB or larger USB 3 drive is a sensible starting point, not a hardware guarantee.

A little room to experiment

Wi-Fi, graphics, audio, sleep and Secure Boot vary by hardware. No internal-drive installer is included. Keep your existing system and backups.

BEFORE YOU GO

Good questions.

Will this replace Windows or my current OS?

Not through the documented live USB setup. RovaOS boots from your USB without an internal-drive installation. Flashing does erase the drive you select, and manually accessing or modifying other disks can still affect their data.

Can I move the same USB to another computer?

Yes, between compatible PCs. With USB saving enabled, your saved workspace travels on that USB. Drivers, firmware, display layouts and performance can differ. Shut down fully before moving the drive.

Why did my changes disappear?

The ISO alone is temporary. Enable USB saving, restart, and check that storage says Persistent USB. If it says Temporary, changes will not survive shutdown. Back up important files separately.

Is this a private or encrypted operating system?

No. The live session has automatic login and administrative access, and saved data is unencrypted. Anyone with the USB may be able to read it. It does not promise anonymity, encryption or a trace-free session.

Can I install it onto my internal drive?

This release is designed for live USB use and does not include an internal-drive installer. Do not use improvised partitioning instructions to install it.

How do I update it?

Back up important files and settings before flashing a newer ISO. Reflashing may erase the save area. Existing full-root save overlays can also override newer system files, so check each release’s instructions and test a spare USB first.
